# Hemasree Randhi | Portfolio Website

A personal portfolio website with a **neon lights + glassmorphism** design, a **dark/light theme toggle**, and highly reactive hover effects. Built with plain HTML, CSS and JavaScript. No frameworks, no build tools.

🔗 **Live site:** https://hemasree-portfoilio-website.netlify.app

---

## ✨ Features

- **Neon + glassmorphism design:** frosted glass cards, glowing borders and text, floating neon background blobs
- **Dark / light mode:** one-click toggle, remembers your choice using `localStorage`
- **Reactive UI:** cards lift and glow on hover, 3D tilt that follows the mouse, animated nav underlines, glowing custom cursor (desktop only)
- **Scroll animations:** fade-in sections, scroll progress bar, animated counters and skill bars
- **Project filters:** filter projects by category with smooth animations
- **Fully responsive:** works on mobile, tablet and desktop, with a hamburger menu on small screens
- **Contact section:** email, social links, "Copy email" button and a mailto contact form
- **No photo:** uses a text/initials-based hero ("HR") instead

## 🚀 How to Run Locally

1. Download or clone the repository:
   ```bash
   git clone https://github.com/Hemasree1738/<your-repo-name>.git
   ```
2. Open the folder.
3. Double-click `index.html` to open it in your browser.

That's it. No installation needed.

---

## 🌐 How to Deploy (Free with GitHub Pages)

1. Push the project to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Source**, choose the `main` branch and the `/ (root)` folder.
4. Click **Save**. Your site will be live in a minute or two.

## 🛠️ Customize It

| What you want to change | Where to do it |
|---|---|
| Text, projects, links | `index.html` |
| Neon colors | CSS variables at the top of `style.css` (`:root`) |
| Light theme colors | The `[data-theme="light"]` block in `style.css` |
| Typing animation roles | The roles array in `script.js` |
| Resume download | Put your PDF in the folder (e.g., `resume.pdf`) and set the button's `href="resume.pdf"` |
| Add a new project | Copy an existing project card in `index.html` and edit it |
